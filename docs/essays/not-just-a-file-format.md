# It’s Not Just a File Format

Every new protocol has its skeptics.

And at some point, someone will say, "Isn’t this just another data exchange format? Maybe a fancy envelope for messages?"

It’s a fair question. But it’s also missing the point.

Because BlockParty is not just a way to wrap data.
It’s a way to express **intent**.
It’s a way to encode **trust**, **ambiguity**, **privacy**, and **impermanence** into the structure of communication itself.

It isn’t just a schema for posts. It’s a social protocol for the modern world—one that actually reflects how people live, change, and disappear.

### Not a Format. A Philosophy.

File formats describe how to parse data.
Protocols describe how to connect systems.

But BlockParty isn’t just concerned with syntax or transport.
It asks deeper questions:
- Who gets to read this?
- Who gets to remember it?
- What happens if the author walks away?
- What happens when a signature becomes suspect?

The answers to those questions aren’t bolted on.
They’re *baked in*.

BlockParty introduces the concept of the **Post-Truth State**:
If someone publishes their root private key—burns it—all their past messages become socially untrustworthy. Still verifiable. Still real. But now open to doubt.

That’s not just data handling.
That’s **dignity by design**.

### Memory That Fades

Most data systems are built for permanence. For big data. For total recall.
BlockParty is built for something more human:
- Blocks can fade from mirrors.
- Identities can be dropped.
- Content lives only if someone cares enough to keep it.

That’s not a bug.
That’s the fix.

### Constraint-Aware by Nature

BlockParty doesn’t assume:
- You’re online.
- You trust the transport.
- You’ll always have access to the same platform.

It works over sneakernet. It works over satellite. It works by printing a QR code.
Because people live in constrained environments, and dignity shouldn’t require uptime.

### Why This Matters

Because communication is more than bytes.
Because permanence is not the same as integrity.
Because what we say and how we’re remembered should be ours to shape—not the platform’s.

So no.
This isn’t just a file format.

It’s a protocol for people.

It’s memory with intent.

It’s trust with an off switch.

And it’s time we started building with that in mind.
